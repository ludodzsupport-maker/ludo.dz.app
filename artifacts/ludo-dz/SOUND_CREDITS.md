# Ludo DZ UI Sound Credits

All UI feedback cues below are original, generated exclusively for this project using ElevenLabs Sound Effects on 2026-08-02. They are provided for use in Ludo DZ under ElevenLabs' generated-audio terms; no third-party copyrighted recordings or samples were used.

Each production cue is mono Ogg Opus, fades out at 140 ms, and measures approximately 146.5 ms including the codec container.

| Category | File | Used for |
| --- | --- | --- |
| Primary action | `public/sounds/primary-action.ogg` | Play, start game, roll dice, replay |
| Secondary / icon | `public/sounds/icon-tap.ogg` | Settings, close, and other small action controls |
| Back / exit | `public/sounds/nav-back.ogg` | Back, dismiss, and exit actions |
| Selection | `public/sounds/selection.ogg` | Game/rule cards, player counts, selectors, board styles, animation speed |
| Language confirmation | `public/sounds/language-change.ogg` | Arabic/French language changes |
| Toggle on | `public/sounds/toggle-on.ogg` | Settings and team-option switches becoming enabled |
| Toggle off | `public/sounds/toggle-off.ogg` | Settings and team-option switches becoming disabled |

The category-to-file mapping is centrally maintained in `src/lib/sound-manager.ts`.
