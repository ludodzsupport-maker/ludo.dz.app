# Project Agent Instructions

## UI design skill

This repository has the Taste Skill UI design rules loaded at `skills/taste-skill/SKILL.md`.

For every upcoming UI implementation, read and follow that skill before changing UI code. Start with the skill's one-line design read, set the `DESIGN_VARIANCE`, `MOTION_INTENSITY`, and `VISUAL_DENSITY` dials, and run the skill pre-flight checklist before finishing.
